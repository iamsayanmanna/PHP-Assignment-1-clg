## ▶️ How to Run

### 1️⃣ Install XAMPP

Download and install **XAMPP** on your computer.

### 2️⃣ Start Apache

Open the **XAMPP Control Panel** and start:

```text
Apache
```

### 3️⃣ Place the Project

Copy the assignment folder into:

```text
C:\xampp_new\htdocs\
```

### 4️⃣ Open in Browser

Start your browser and visit:

```text
http://localhost/
```

Then open the PHP Assignment folder.

### 5️⃣ Run an Individual Program

For example:

```text
http://localhost/PHP-Assignment%20%E2%80%93%201/1st.php
```

You can replace `1st.php` with any other PHP file from the repository.
